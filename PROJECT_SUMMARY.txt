## User Experience

1. Install: dotnet add package Optimizely.Performance.DotNetCounters
2. See: Build message directing to App_Data/Optimizely.PerformanceCounters/
3. Find: Configuration templates for their version
4. Copy: Template content to web.config or appsettings.json
5. Configure: Application Insights key
6. Deploy: Library auto-initializes
7. Monitor: Metrics flow to Application Insights
